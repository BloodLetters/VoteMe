# VoteMe IPC Listener Guide

This guide explains how external Pumpkin plugins can listen to and consume real-time vote events from **VoteMe** using Pumpkin's IPC system

## 1. IPC Protocol Specification

Communication uses UTF-8 encoded JSON byte slices over Pumpkin's synchronous IPC channel.

### 1.1. Available Actions

Send one of the following JSON payloads to the `"voteme"` plugin:

| Action | Request Payload | VoteMe Response | Purpose |
|---|---|---|---|
| **Subscribe** | `{"action":"subscribe"}` | `{"status":"ok","message":"Plugin '...' subscribed to vote events."}` | Registers your plugin to receive vote events. |
| **Unsubscribe** | `{"action":"unsubscribe"}` | `{"status":"ok","message":"Plugin '...' unsubscribed from vote events."}` | Removes your plugin from the subscriber list. |
| **Ping** | `{"action":"ping"}` | `{"status":"ok","message":"pong"}` | Health-check to verify VoteMe IPC availability. |

### 1.2. Broadcast Event Schema (`vote_received`)

When a valid vote arrives, VoteMe delivers this JSON payload to all subscribed plugins:

```json
{
  "event": "vote_received",
  "vote": {
    "service_name": "PlanetMinecraft",
    "username": "Steve",
    "address": "127.0.0.1",
    "timestamp": "1727136000",
    "source_address": "127.0.0.1",
    "is_v2": true
  }
}
```

#### Field Reference:
- `event` (*string*): Always `"vote_received"`.
- `vote.service_name` (*string*): Name of the voting website or service list.
- `vote.username` (*string*): Sanitized Minecraft username of the voter (max 16 characters).
- `vote.address` (*string*): Voter IP address reported by the voting website.
- `vote.timestamp` (*string*): Timestamp string generated by the voting website.
- `vote.source_address` (*string*): Upstream IP address connected to VoteMe's socket.
- `vote.is_v2` (*boolean*): `true` for NuVotifier v2 (HMAC-SHA256 token), `false` for legacy v1 (RSA).

## 2. Complete Implementation Example

### 2.1. `Cargo.toml`

```toml
[package]
name = "vote_reward"
version = "0.1.0"
edition = "2024"

[lib]
crate-type = ["cdylib"]

[dependencies]
pumpkin-plugin-api = { git = "https://github.com/Pumpkin-MC/Pumpkin", tag = "0.2.0+26.3-26.51" }
serde = { version = "1.0", features = ["derive"] }
serde_json = "1.0"

[profile.release]
lto = true
```

### 2.2. `src/lib.rs`

```rust
use pumpkin_plugin_api::{Context, Plugin, PluginMetadata, Result, register_plugin};
use serde::Deserialize;

#[derive(Debug, Deserialize)]
pub struct VoteReceivedEvent {
    pub event: String,
    pub vote: VoteData,
}

#[derive(Debug, Deserialize)]
pub struct VoteData {
    pub service_name: String,
    pub username: String,
    pub address: String,
    pub timestamp: String,
    pub source_address: String,
    pub is_v2: bool,
}

pub struct VoteReward;

impl Plugin for VoteReward {
    fn new() -> Self {
        Self
    }

    fn metadata(&self) -> PluginMetadata {
        PluginMetadata {
            name: "vote_reward".into(),
            version: "0.1.0".into(),
            authors: vec!["ServerAdmin".into()],
            description: "Listens to VoteMe vote events for in-game rewards".into(),
            dependencies: vec!["voteme".into()],
            permissions: vec![],
        }
    }

    fn on_load(&self, _context: Context) -> Result<()> {
        let subscribe_payload = br#"{"action":"subscribe"}"#;
        match pumpkin_plugin_api::ipc::send_ipc_message("voteme", subscribe_payload) {
            Ok(Ok(response_bytes)) => {
                let text = String::from_utf8_lossy(&response_bytes);
                println!("[VoteReward] Connected to VoteMe: {text}");
            }
            Ok(Err(error)) => {
                eprintln!("[VoteReward] VoteMe rejected subscription: {error}");
            }
            Err(()) => {
                eprintln!("[VoteReward] Failed to contact VoteMe. Ensure VoteMe is loaded.");
            }
        }
        Ok(())
    }

    fn on_unload(&self, _context: Context) -> Result<()> {
        let unsubscribe_payload = br#"{"action":"unsubscribe"}"#;
        let _ = pumpkin_plugin_api::ipc::send_ipc_message("voteme", unsubscribe_payload);
        Ok(())
    }

    fn handle_ipc_message(&self, sender: String, message: Vec<u8>) -> Result<Vec<u8>, String> {
        if sender != "voteme" {
            return Ok(Vec::new());
        }

        let event_data: VoteReceivedEvent = match serde_json::from_slice(&message) {
            Ok(data) => data,
            Err(error) => {
                eprintln!("[VoteReward] JSON parsing failed: {error}");
                return Ok(Vec::new());
            }
        };

        if event_data.event == "vote_received" {
            let vote = &event_data.vote;
            println!(
                "[VoteReward] Vote received: Player='{}', Service='{}', IP='{}', ProtocolV2={}",
                vote.username, vote.service_name, vote.address, vote.is_v2
            );
        }

        Ok(Vec::new())
    }
}

register_plugin!(VoteReward);
```

## 3. Key Best Practices

1. **Verify the Sender**: Always check that `sender == "voteme"` before parsing incoming messages.
2. **Safe Deserialization**: Use `serde_json::from_slice` with pattern matching (`match` or `if let`) instead of `.unwrap()` to prevent crashes on unexpected payloads.
3. **Clean Teardown**: Always dispatch `{"action":"unsubscribe"}` inside `on_unload` to keep VoteMe's subscriber registry clean.
